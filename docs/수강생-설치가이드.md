# A4P 통합검색 설치 가이드 (수강생용)

구글·네이버·Bing·유튜브에서 검색하면, **내 옵시디언 노트가 검색 결과 옆에 함께 나타나는** 도구입니다.
설치는 5단계이고, 한 번만 하면 됩니다. 천천히 따라오세요. 🙂

> ⏱️ 예상 소요 시간: 10~15분

---

## 1단계. Tampermonkey 설치 (브라우저 확장)

1. Chrome 웹스토어에서 **[Tampermonkey](https://www.tampermonkey.net/)** 를 설치합니다.
2. 주소창에 `chrome://extensions` 를 입력해 확장 프로그램 페이지를 엽니다.
3. **Tampermonkey → 세부정보**에서 아래 3가지를 확인합니다:
   - **사용자 스크립트 허용(Allow User Scripts)** → **켜기** (가장 중요! 이게 꺼져 있으면 아무것도 안 나옵니다)
   - **사이트 액세스** → **모든 사이트에서**
   - **파일 URL에 대한 액세스 허용** → 켜기 (선택)

`[스크린샷: Tampermonkey 세부정보 토글 3개]`

## 2단계. A4P 유저스크립트 설치

1. 강의에서 안내한 링크(또는 `userscript/a4p-omnisearch.user.js` 파일)를 클릭합니다.
2. Tampermonkey가 설치 화면을 띄우면 **설치**를 누릅니다.

`[스크린샷: Tampermonkey 설치 확인 화면]`

## 3단계. 옵시디언 필수 플러그인 설치

옵시디언 → 설정 → **커뮤니티 플러그인**에서 두 개를 설치·활성화합니다:

1. **Omnisearch** (필수) — 볼트 검색 엔진
2. **Local REST API** (권장) — 본문 미리보기·성경구절 칩·신학 주제 칩에 필요

`[스크린샷: 커뮤니티 플러그인 검색 화면]`

## 4단계. A4P Omnisearch Helper 설치 + 자동 설정

1. 강의에서 배포한 `a4p-omnisearch` 폴더(manifest.json / main.js / styles.css)를
   내 볼트의 `.obsidian/plugins/a4p-omnisearch/` 에 복사합니다.
2. 옵시디언 설정 → 커뮤니티 플러그인에서 **A4P Omnisearch Helper**를 활성화합니다.
3. 설정 탭 → **A4P Omnisearch Helper**를 열면 체크리스트가 보입니다.
   ❌ 항목 옆의 **[⚡ 자동 설정]** 버튼을 눌러 모두 ✅로 만듭니다.

`[스크린샷: Helper 설정 탭 체크리스트]`

## 5단계. 설정 코드 연결 (마지막!)

1. Helper 설정 탭에서 **[📋 설정 코드 복사]** 버튼을 누릅니다.
2. 구글에서 아무거나 검색한 뒤, 오른쪽에 나타난 **A4P 통합검색 위젯의 ⚡ 버튼**을 누릅니다.
3. 복사한 코드를 붙여넣고 확인 → 페이지가 새로고침되면 완료! 🎉

> 💡 첫 검색 때 Tampermonkey가 "localhost 접근을 허용할까요?"라고 물으면 **항상 도메인 허용**을 선택하세요.

---

## 🔐 꼭 지켜주세요

- **설정 코드는 절대 다른 사람과 공유하지 마세요.** 코드 안에 내 볼트의 API 키와 컴퓨터 경로가 들어 있습니다.
- 이 도구는 모두 **내 컴퓨터 안에서만**(localhost) 동작합니다. 노트 내용이 외부 서버로 전송되지 않습니다.

## 사용 팁

| 하고 싶은 것 | 방법 |
|---|---|
| 성경구절로 검색 | `요 3:16`, `요한복음 3장 16절`, `시편 23편` 처럼 검색 — 구절 카드가 위에 고정됩니다 |
| 이 구절로 설교한 적 있나? | 구절 카드의 **🔎 인용한 노트 찾기** 클릭 |
| 설교만 / 조각만 보기 | 결과 위 **카테고리 칩** (전체·설교·조각·묵상·성경·주석) 클릭 |
| 설교문에 인용 붙이기 | 카드에 마우스 올리고 **인용** 버튼 (또는 키보드 `c`) |
| 내 볼트 폴더 이름이 달라요 | Helper 설정 탭 → "자료 위치"에서 **[자동 감지]** 클릭 (또는 직접 입력) → 설정 코드 다시 복사 → ⚡에 붙여넣기 |
| 화면이 너무 밝아요/어두워요 | 위젯 헤더의 **◐ 버튼** 클릭 — 자동(OS 따라감) → 라이트 → 다크 순환 |
| 유튜브에서도 쓰고 싶어요 | 유튜브 **검색결과 페이지**에서 오른쪽 플로팅 패널로 나타납니다 (영상 시청 중에는 안 보임) |
| 뭔가 안 돼요 | 위젯의 **🩺 버튼** → 진단 결과의 안내를 따르세요 |

## 자주 묻는 질문

**Q. 위젯이 아예 안 보여요.**
1단계의 "사용자 스크립트 허용" 토글을 확인하세요. Chrome 138 이후 이 토글이 꺼져 있으면 스크립트가 실행되지 않습니다.

**Q. "옵시디언과 연결할 수 없습니다"라고 나와요.**
옵시디언이 켜져 있는지 확인하고, Helper 설정 탭에서 체크리스트가 모두 ✅인지 확인하세요.

**Q. 본문 미리보기가 안 나오고 요약만 나와요.**
Local REST API 플러그인(3단계)을 설치하고 Helper에서 [⚡ 자동 설정] 후, 설정 코드를 **다시 복사**해서 ⚡에 붙여넣으세요.

**Q. 노트를 클릭했는데 옵시디언이 안 열려요.**
브라우저가 "obsidian:// 링크를 열까요?"라고 물으면 허용을 선택하세요.
